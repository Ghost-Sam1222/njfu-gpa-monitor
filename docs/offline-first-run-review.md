# 离线首次配置审查

日期：2026-10-27。

## 范围

使用空白的内存配置、虚构账号与通知渠道，运行现有设置页和真实请求处理逻辑；GitHub 操作、教务查询及通知测试结果全部替换为模拟响应。临时服务器仅监听本机，外部命令和网络请求被拦截。不读取真实 Secrets，不创建仓库、不部署、不发通知、不改线上配置。

这不是全新 GitHub 账户从模板创建仓库、授权 Codespace 到实际通知送达的端到端验收。

## 发现与最小修复

通知测试成功时，原页面统一显示“教务登录、配置和通知测试均已成功”和“部署成功”。即便保留旧凭据、没有重新验证登录，或定时监控仍关闭，也会出现这些提示。

保存接口现在分别返回本次登录是否已验证、实际保存的监控开关；页面分别说明配置保存、通知测试、登录验证和监控状态。不改变登录、定时任务或推送逻辑，不新增依赖。

## 验证结果

- 空白账号或未经验证的新凭据不能保存，不写入任何设置。
- 缺少学期不能验证；验证后更改学期必须重新验证。
- 没有完整通知渠道不能保存。
- 合成空成绩表明确提示“暂无已公布成绩”，不解释为全部出分。
- 验证后可以在监控关闭、日期留空、考试安排未读取的情况下保存；生成独立状态盐，密码不进入公开 Variables 或接口响应。
- 保存不启动成绩或考试查询。选择通知测试时只触发通知测试工作流；保留旧凭据不会冒称本次已验证登录。
- 启用监控但未填停止日期时拒绝保存，不产生部分写入。
- 浏览器使用合成邮件渠道走通验证、保存、保留旧凭据再次保存；390 像素手机宽度无横向溢出，明确显示监控未开启。
