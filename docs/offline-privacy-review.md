# 离线隐私交付审查

日期：2026-10-27。

## 审查边界

仅核查当前仓库的生产代码、工作流、本地 Pages 发布源和已有导出路径。测试全部使用合成身份、密码、Cookie、代理地址、通知密钥及成绩，并替换网络、SMTP 和教务查询。不读取真实 Secrets 或私人仓库，不登录、不发送通知、不启动 Actions、不上传或部署。

课程成绩发往用户配置的通知渠道、完整 HTML 成绩单发往指定邮箱，属于 README 明示的预期行为，不视为泄漏。仓库所有者、仓库名称、普通 Variables、运行状态和考试汇总日期也属于明确公开的配置或状态。

## 已复现并修复的问题

通知地址误带空格时，标准库会抛出 `http.client.InvalidURL`，异常文本包含请求路径。它不是原有处理的 `URLError` 或 `OSError`，会绕过通知错误封装，使 Actions 程序退出时打印地址片段。异常 HTTP 状态行也存在同类问题，可能输出远端原始内容。不能依赖 GitHub 对完整 Secret 的掩码来隐藏 URL 片段。

在通用通知与 Bark 两处网络封装中补充处理标准库 `HTTPException`，沿用已有的“仅输出异常类型”策略。没有增加依赖、通用脱敏框架或其他功能。

合成回归测试先复现两条路径失败，修复后确认程序返回明确失败状态，日志只有错误类型，没有合成私密地址、设备密钥或远端响应内容。此结果证明存在潜在泄漏路径，不证明任何真实密钥已经泄漏。

## 其余核查结果

- 本地公开入口只收集 GitHub 所有者与仓库名称，不包含教务或通知凭据表单。渠道教程、字幕和图标不含此次运行数据；两份图标内容相同，图像未展示个人资料。
- 成绩单由邮件投递路径生成到配置的报告目录；工作流未上传报告 Artifact，也没有把报告复制进 `docs/` 的步骤。设置服务器没有下载报告或诊断包的路由。
- 用合成成绩执行真实监控编排、生成临时 HTML 并模拟 Bark/SMTP 投递，确认课程与分数只出现在预期投递内容中；日志和缓存均不含合成身份、凭据、课程明细或分数，成绩单不含原始登录或通知凭据。
- SMTP 认证失败测试确认只输出异常类型，不回显认证信息或服务器响应。
- 现有考试工作流采用汇总输出；原始考试 JSON 是文档明确限制在个人设备或私有 Codespace 使用的可选 CLI 输出，不属于自动公开导出。

新增 4 个测试，全部 140 个测试通过；Python 编译与差异检查通过。临时报告自动清理，未改动用户原有产物。

## 不作出的承诺

没有检查线上 Pages 设置、历史提交、既往 Actions 日志、外部托管教程视频或通知服务的留存策略，因此不能据此认定历史从未泄漏。公开仓库的 Variables 和日志仍可见；通知服务、GitHub Runner 仍会按设计处理必要数据。本次不等于全新用户完整云端部署验收，也不保证未来外部接口永久不变。
